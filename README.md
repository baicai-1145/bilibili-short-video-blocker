# bilibili-short-video-blocker

Chrome 插件：按照自定义阈值隐藏 B 站时长过短的视频推荐，包括首页/分区卡片以及视频播放页右侧推荐栏。

## 使用方式

### 下载安装

1. 打开项目发布页：`https://github.com/baicai-1145/bilibili-short-video-blocker/releases`。
2. 在最新的 Release 中找到 `Source code (zip)`，点击下载。
3. 将下载得到的 zip 文件解压到任意本地目录（例如 `D:\bilibili-short-video-blocker`）。

### 在 Chrome 中加载扩展

1. 在地址栏输入 `chrome://extensions/` 打开扩展管理页面。
2. 打开右上角的“开发者模式”（Developer mode）。
3. 点击“加载已解压的扩展程序”（Load unpacked），选择上一步解压后的目录（包含 `manifest.json` 的文件夹）。
4. 加载成功后，你会在扩展列表中看到 “bilibili-short-video-blocker”。

### 配置与使用

1. 点击浏览器工具栏中的扩展图标，打开弹窗即可快速修改“短视频阈值”（单位：秒）。  
   - 阈值为 `0` 表示禁用过滤（不隐藏任何视频）。  
   - 默认阈值为 `180` 秒。
2. 你也可以设置关键词规则、UP 主白名单等高级选项。
3. UP 主黑名单强力过滤（基于 UID 纯数字唯一匹配）：
   - 自动同步你在 B 站已拉黑的 UP 主 UID（通过 B 站黑名单接口）；
   - 支持在设置中手动添加自定义黑名单 UID（支持输入纯数字 UID 或个人主页链接）；
   - 只比对唯一不可伪造的 UID，不受 UP 主改名影响；
   - 凡是命中黑名单 UID 的 UP 主视频，**无条件强制彻底屏蔽（不限时长）**，彻底解决 B 站官方推荐算法依然推送已拉黑 UP 主的问题。
4. 单个视频一键拉黑（彻底消灭买量/强推视频）：
   - 悬浮一键屏蔽：在首页或侧边栏将鼠标悬停在任意视频卡片右上角，点击浮现的 ✕ 按钮即可一键拉黑；
   - 手动输入拉黑：支持在扩展弹窗中直接粘贴 BV 号或视频链接进行拉黑；
   - 永久屏蔽：被拉黑的视频将从所有推荐位（首页、分区、右侧推荐栏）彻底抹去；
   - 可视化管理：在扩展设置面板中可随时查看已拉黑的视频列表并一键解除。
5. 隐藏运营推广位：自动识别并直接隐藏 B 站塞在推荐流里的付费运营推广卡（如视频页右侧推荐栏置顶的明星/品牌推广视频），无需手动拉黑，可在设置中开关。
6. 完播界面优化：视频播放结束后，自动隐藏推荐视频网格并抹除发白模糊水印，将原生操作栏（重播、点赞、投币、收藏、分享等）居中优雅展示（可在选项中自由开关）。
7. 配置完成后，回到 bilibili 页面刷新，时长低于阈值且命中规则的视频卡片会被自动隐藏（包括首页、分区页和视频播放页右侧推荐栏）。
